Simulation by description

VibeSim turns a short written description of a robot into a running simulation: the joints, the servos, the payload, the goal. No model to download, no licence to sign. The description is the scene.

What the description says

  • The machine

    Which arm, and where every joint starts. The bench models the SO-101's published joint ranges and servo limits.

  • The goal

    The point in space the tool must reach, in millimetres. Inverse kinematics finds joint angles that get there, inside their ranges.

  • The load

    What the gripper holds, in grams. Gravity and the payload show up as torque on every servo along the chain.

How it works

  1. Write it. One JSON description: the machine, the start pose, the goal, the load.
  2. Run it. The engine solves the joint angles, then steps each servo at one kilohertz until the arm settles.
  3. Read it. The bench reports where the tool ended, how long it took, and the largest torque a servo used.

The engine is copied from CommandAGI's own simulation core: the same robot model, the same servo step, the same inverse kinematics. A scene and its commands fully determine a run.
