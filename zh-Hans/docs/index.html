描述格式

VibeSim 的描述是一个 JSON 对象。它写明机器、每个关节的起始位置、工具要到达的点和夹爪夹着什么。实验台读取它并运行。

一个例子

{
  "machine": "so101",
  "start": {
    "shoulder_pan": 0,
    "shoulder_lift": 0.54,
    "elbow_flex": 0,
    "wrist_flex": 0,
    "wrist_roll": 0,
    "gripper": 1.74
  },
  "goal_mm": [80, -200, 60],
  "payload_g": 0
}

字段

字段含义
machine哪条机械臂。目前实验台只有一条：so101，即 SO-101，采用其公布模型的关节范围和舵机限值。
start每个关节的起始角度，单位弧度，必须在该关节范围内。缺少一个即为错误：场景从不猜测。
goal_mm工具要到达的点，单位毫米：[x, y, z]，机械臂坐标系，z 向上。
payload_g夹爪夹着什么，单位克。引擎把它加进重力已经施加在链条上的扭矩。

一次运行做了什么

  1. 逆运动学。阻尼最小二乘法求出让工具点落到目标上的关节角度，并保持在每个关节的范围内。
  2. 舵机步进。每个关节是一个位置舵机：扭矩由误差和速度得出，受关节上限限制，并抵消重力、负载、阻尼和摩擦。每秒一千步，按舵机刚度分成更小的子步。
  3. 静止。当每个关节距目标小于 2 毫弧度且不再移动时结束，最多六秒。

实验台报告什么

工具最终停在哪里、机械臂用了多久、任何一个舵机使用的最大扭矩。目标不可达时，实验台会说明这一点以及差了多少：不会假装到达。

目前的限制

一台机器；点目标；暂不与世界碰撞，也还没有其他物理。引擎是 CommandAGI 的仿真内核，复制到本网站（engine/），因此一段场景和它的指令完全决定一次运行。告诉我们你接下来想要哪台机器：hello@vibesim.pro。
